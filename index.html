How a part gets made

design → machine → finish → inspect
  1. 01

    Design

    We model each part in CAD against the load case it'll actually see, not a generic spec — a track hub and a touring hub start from different math.

  2. 02

    Machine

    Billet titanium and stainless go on the lathes and mills. Every fixture is dialed in to ±0.003mm before the first cut is taken.

  3. 03

    Finish

    Bead blast, polish, or hard anodize, done by hand so the surface texture is consistent from the first part in a batch to the last.

  4. 04

    Inspect

    Every part is measured on a CMM against its drawing before it's boxed. Nothing ships on a sample check alone.
